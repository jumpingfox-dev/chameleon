# Chameleon 1.1.4 (build 6)

## Google Play "What's new" (en-US, under 500 characters)

```
Much faster loading: genres, Home and search now open in a fraction of the time.
Surround sound and passthrough now reach your receiver, TrueHD included.
Home keeps your place and stays as you left it after watching something.
New Server page in Settings, with a library scan for admins.
Smoother scrolling along rows with the remote.
Accounts that no longer exist are removed automatically.
```

## Full changes

**Speed**
- Movies and shows are now asked for separately and merged: the server answers each in about
  a tenth of a second, but both together in two to three seconds.
- Lists no longer ask the server for a total count they don't use, which cost about a second
  each.
- A genre loads whole in two requests and works out its A–Z bar itself, instead of 27 extra
  requests (about 8 seconds down to well under one).

**Playback**
- mpv plays audio through Android's AudioTrack output instead of OpenSL ES, which was stereo
  only: passthrough now actually reaches the receiver (Dolby, DTS and TrueHD), and decoded
  surround stays surround.
- The seek bar is white, and the theme's color while scrubbing.
- The age rating sits closer to the top bar, lined up with the back arrow.

**Home**
- Focus is never lost: if the item you're on goes away (a row refreshing), focus goes back to
  it, or to whatever now sits in its place.
- Moving along a row with the remote keeps the focused card in the same spot (the last one
  that fits whole), and the card before it no longer peeks out of the margin.
- After watching something, only Continue Watching and Next Up update; everything else stays
  as it was.
- Play and More info, and the detail pages' Play and Favorite, are rounded rectangles again.

**Search and settings**
- Search in the sidebar opens the Search page.
- People in search results show the focus ring.
- New Server page: connection details, response time, library counts, and for administrators
  a library scan with progress and who's watching now.
- Saved accounts the server no longer accepts are removed, and renamed ones are updated.
